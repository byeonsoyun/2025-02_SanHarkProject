## 시스템 동작 방식

### 자동 복잡도 감지
시스템이 질문을 분석하여 자동으로 처리 방식을 결정합니다:

**단순 검색 → 데이터베이스**
- 키워드 중심 질문
- 사례 검색 요청
- 짧은 질문 (10자 이하)

**복잡 분석 → AI 처리**
- "어떻게", "왜", "무엇" 등 분석 키워드
- "요건", "기준", "방법" 등 법리 용어
- "차이", "비교", "설명" 등 해석 요청
- 15자 이상의 복잡한 질문

## 검색 결과 이해하기

### 벡터 유사도 거리
- **7.0 이하**: 매우 관련성 높음 (거의 동일한 주제)
- **7.0-9.0**: 관련성 높음 (유사한 법률 쟁점)
- **9.0-11.0**: 관련성 있음 (같은 법률 분야)
- **11.0 이상**: 관련성 낮음 (다른 주제)

### 판례 정보
각 검색 결과는 다음 정보를 포함합니다:
- **document_id**: 법원명-사건번호 (예: 서울고등법원-2016나2044774)
- **title**: 사건명 (예: 부당이득반환청구의소)
- **content**: 판결문 전문
- **distance**: 유사도 거리 (낮을수록 관련성 높음)

## 문제 해결

### 검색 결과가 없을 때
1. 키워드를 더 일반적으로 변경
   - "아파트 매매" → "부동산 매매"
   - "렌트카 사고" → "교통사고"

2. 법률 용어 사용
   - "집 계약 파기" → "계약 해제"
   - "돈 안 줌" → "채무불이행"

### AI 답변이 느릴 때
- GPU 서버 연결 확인: `curl http://10.198.138.249:22434/api/tags`
- 로컬 모드로 전환: `python switch_ollama.py local`
